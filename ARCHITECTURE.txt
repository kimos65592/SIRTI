J.A.R.V.I.S COGNITIVE OS — FULL CORE
======================================
Web laboratory:
- Perception
- Understanding / Intent
- World Model
- Persistent Memory
- Self Model
- Goals / Tasks
- Multi-plan Planner
- Prediction
- Decision Engine
- Permission abstraction
- Tool Engine
- Observation / Verification
- Reflection / Learning
- Personalization
- Voice output
- Event Bus
- Persistent settings/goals/memory
- Android Bridge abstraction (web-safe placeholder)

Important:
The web build cannot directly control Android apps, notifications,
files, accessibility, or background services. Those capabilities
require the Android Bridge and Android permissions in the APK.
The cognitive core is separated from those capabilities so the
same logic can be connected to native Android later.
